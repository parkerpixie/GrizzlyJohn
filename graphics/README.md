# GrizzlyJohn Graphics

Asset drop zone for GrizzlyJohn.

## Facebook / share cards

The horizontal share artwork Jen is uploading is designed for Facebook/Open Graph sharing. Use **1200 × 630 px (1.91:1)** as the working target when creating new share cards so the collection stays consistent.

Suggested filenames:
- `share-[topic].png`
- `share-wisdom-[slug].png`
- `share-quest-[slug].png`
- `share-park-[slug].png`

## App artwork

This folder can also hold GrizzlyJohn artwork as we build it out. Suggested future organization:
- `app-icon.png`
- `hero/`
- `share/`
- `parks/`
- `badges/`

For now, feel free to upload the horizontal Facebook share cards directly into `/graphics`. We can sort them into subfolders later once the asset library gets big enough to need adult supervision.
